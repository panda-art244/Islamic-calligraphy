# Islamic Calligraphy

A computer vision prototype for image processing and digital cultural heritage research.

## Features

- Image upload and preprocessing
- Circular-object detection using OpenCV
- CLAHE contrast enhancement
- Adaptive thresholding and sharpening
- Edge detection and image statistics
- Export results as PNG and JSON

## Technologies

- Python
- OpenCV
- NumPy
- Pillow
- Streamlit

## Installation

Install dependencies:

    pip install -r requirements.txt

Run the application:

    streamlit run app.py

## Limitations

This prototype processes images but does not automatically identify coins or recognize, transcribe, or translate calligraphy.

## Purpose

An exploratory project at the intersection of computer vision, Islamic art, and digital cultural heritage.
